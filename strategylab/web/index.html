3 · Parameter optimieren

Mehrere Parameterwerte durchprobieren (mit | trennen, z. B. 10|20|30) und nach Kennzahl sortieren.

⚠️ Dies ist ein In-Sample-Ergebnis: Auf denselben Daten optimierte Parameter sehen fast immer zu gut aus. Prüfe die Sieger im Reiter Walk-Forward.

4 · Walk-Forward-Analyse — funktioniert es auch in Zukunft?

Parameter werden nur auf vergangenen Daten optimiert und dann auf dem folgenden, ungesehenen Zeitraum getestet. So sieht man, ob eine Strategie überangepasst ist.
